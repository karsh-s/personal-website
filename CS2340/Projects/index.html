GT Movie Store!

Django · Bootstrap · PythonAnywhere

Description: This is a movie store developed using Django and Bootstrap. It is also hosted on PythonAnywhere. The store has several screens which include the home screen, an about screen, movie screen and your cart/orders. Users have the ability to sign up and make accounts. They can browse movies that are available, read their description and add them to cart. Users also have the ability to write reviews. Once a review is written, they can delete the review or edit it. If a user doesn't like what someone has said and it is inappropriate, they can report the review. Other than that, users can search for the movie and also see their previous orders. As an admin, you can manage users, movies and also reviews that are available on the GT Movie Store. On top of that, admins can see and manage orders that have been purchased through the store. As such, all user stories have been accomplished.

Live at https://ksachdeva33.pythonanywhere.com/
